rebel iptv · 11 an optional companion

A second server, folded in

Rebel IPTV is a self-hosted IPTV server with its own playlist, guide and dashboard. masqueradarr can run it beside itself as an opt-in companion: its channels and guide join your catalog, it is kept updated and health-checked from Settings → Rebel IPTV, and its own dashboard pops up through masqueradarr when you need to configure it.

01 What you get

Off by default, one switch to turn on

Rebel IPTV carries 480+ US / CA / UK / AU linear channels plus live sports, with its own M3U, XMLTV and dashboard. Nothing about it runs until you ask for it — with the switch off there is no Rebel container and masqueradarr's side of the integration stays dormant.

● catalog + guide

A first-class source

Rebel's channels arrive through a normal rebel source adapter and its guide self-links to every channel — no Channel Mapping needed.

● playback

Always through the origin

Rebel serves continuous MPEG-TS, so its channels always ride the local origin: one ingest per channel, in-app HLS, Active Streams and telemetry.

● lifecycle

Updates with rollback

With Docker access on, masqueradarr is Rebel's update path: check, pull, recreate, health-wait — and roll back if the new container doesn't come up.

● dashboard

Behind your admin login

Open Rebel IPTV pops its dashboard up through an admin-only gate on port 3080, revoked within 30 s when your session ends.

license

Rebel IPTV is closed-source and licensed for personal, non-commercial use, in binary / container form only — no modification, redistribution or reverse-engineering. masqueradarr therefore never bundles, extracts or rebuilds it: Rebel always runs as its own, unmodified rebeliptv/iptv container, pulled by your Docker, and its dashboard is served at its own root, byte-for-byte.

02 Topology

Rebel sits on its own private network

Rebel never faces your LAN directly. masqueradarr reaches it over a private network — for its playlist and guide (Node) and for its streams (Rust) — and fronts its dashboard with a second listener of its own.

03 Enabling it

Three ways to run it

Pick the shape that matches how you deploy masqueradarr. In every case masqueradarr either adopts a Rebel you run (REBEL_IPTV_URL set) or manages one it creates itself (REBEL_IPTV_URL unset — which needs Docker access).

Compose stack — flip one line

The rebel-iptv service already lives in docker-compose.yml at scale: 0 (the same switch pattern as docker-sock-proxy). REBEL_IPTV=1 scales it to one container and enables masqueradarr's side of the integration, so the two can't drift.

# .env
REBEL_IPTV=1

# then
docker compose up -d

Setting REBEL_IPTV back to 0 and running docker compose up -d removes the Rebel container but keeps its data volume.

All-in-one image — managed sibling

With DOCKER_SOCK_ACCESS=1 and the socket mounted, masqueradarr creates the network masq-rebel-net, the volume masq-rebel-iptv-data and the container masq-rebel-iptv, then connects itself to that network.

docker run -d --name masqueradarr -p 3000:3000 -p 3080:3080 \
  -e REBEL_IPTV_ENABLED=true -e DOCKER_SOCK_ACCESS=1 \
  -v masqueradarr-data:/data -v /var/run/docker.sock:/var/run/docker.sock \
  iflip721/masqueradarr-aio:latest

All-in-one image — adopt your own (no socket)

With DOCKER_SOCK_ACCESS=0, run Rebel yourself on a shared network and point masqueradarr at it.

docker network create rebel-net
docker run -d --name rebel-iptv --network rebel-net --network-alias rebel-iptv \
  -v rebel-iptv-data:/app/data --restart unless-stopped rebeliptv/iptv:latest
docker run -d --name masqueradarr --network rebel-net -p 3000:3000 -p 3080:3080 \
  -e REBEL_IPTV_ENABLED=true -e REBEL_IPTV_URL=http://rebel-iptv:8080 \
  -v masqueradarr-data:/data iflip721/masqueradarr-aio:latest

05 Catalog & playback

A rebel adapter like any other

Rebel is a first-class source adapter, registered only while the companion is enabled. Nothing in the core special-cases it — what it needs, it declares.

● sync

Host-free entries

A sync fetches /playlist over the internal network and stores each channel as rebel://channel/<tvg-id>. No Rebel host, port or key is ever stored.

● resolve

Re-based per play

At play time the adapter looks the tvg-id up in a fresh playlist, re-bases the stream URL onto Rebel's current address, and refuses anything that points off Rebel's own host.

● originRequired

One ingest per channel

Rebel serves continuous MPEG-TS, so the adapter forces the local origin whatever the proxy config says: one raw-TS ingest per channel feeds the RAM ring, giving in-app HLS playback, Active Streams and telemetry.

● stream cap

Match Rebel's own limit

Max simultaneous streams in the tab caps how many different Rebel channels play at once — set it to Rebel's own Simultaneous streams (default 4). A channel over the cap is refused with a 429 unless a failover backup on another provider can carry it.

● guide

Self-linked

The guide comes from /epg.gz and self-links to every channel; tvg-ids are Rebel's stable ids such as us-espn.

● when Rebel is down

Your channels stay

If Rebel is unreachable or rejects the key, a sync keeps your existing channels and flags the playlist warn.

06 Docker socket access

One switch: DOCKER_SOCK_ACCESS

A single, app-wide switch gates every Docker-dependent feature, now and in future. It is off by default, because Docker API access is root-equivalent on the host: anything that compromised masqueradarr could start a privileged container.

● 1 · on

Restricted API access

Compose starts docker-sock-proxy (tecnativa/docker-socket-proxy — only the containers, images and networks sections, on an internal-only network) and points the app at it; the AIO entrypoint adds the app's node user to the mounted socket's group. The app logs one boot WARN. The proxy narrows which endpoints exist — it is not a security boundary — so masqueradarr additionally refuses to create privileged containers, host namespaces, devices, or binds other than Rebel's /app/data.

● 0 · off (default)

No socket anywhere

No socket is mounted — the proxy has scale: 0, so it is never created — and the AIO image never grants one even if you mount it (it logs that it refused). Docker-dependent features run in their reduced mode: for Rebel, catalog, guide, playback and the pop-up still work, but you force-pull its new images by hand.

0 or 1 — nothing else

The value doubles as the proxy's compose scale, so true makes docker compose config fail. DOCKER_SOCK_PATH overrides the host socket path for rootless Docker (default /var/run/docker.sock).

the data plane can never reach the socket proxy

With access on, the socket proxy's endpoint is refused as a stream upstream even for a grant that allows private addresses — by name, by its resolved addresses (refreshed every 60 s), and in the data plane's upstream DNS resolver, so an alias that resolves to it is refused too. Every redirect hop passes the same SSRF gate as the first request. Ordinary LAN and single-label names (a NAS, rebel-iptv) keep their usual verdicts.

  • Interrupted updates resolve at boot. An update cut short by a masqueradarr restart is resolved at the next start, so Rebel is never left half-replaced.
  • Auto-update is on by default when Docker access is on: nightly at 04:00 (editable), and only when idle — it waits while anyone watches a Rebel channel, and runs anyway after 3 deferrals, because a stale Rebel stops serving channels.
  • Pinned tags are info-only. With a non-latest REBEL_IPTV_IMAGE, new releases are shown, never installed.
08 The Settings tab & the pop-up

Settings → Rebel IPTV

The tab appears only while the companion is enabled (REBEL_IPTV=1 in the compose stack, or REBEL_IPTV_ENABLED on the AIO image). Updating, restarting and reading logs need Docker access; with it off the tab says so, disables those buttons, and shows the command to pull new Rebel images by hand.

● status

Container state, Docker health, reachability and current viewers.

● updates

Installed vs. latest release, Check now, Update now with automatic rollback, and the idle-aware auto-update window.

● connection & catalog

Playlist API key, max simultaneous streams, Test, Add Rebel IPTV playlist / Sync now.

● actions

Open Rebel IPTV — its own dashboard, through the admin-only gate on port 3080.
