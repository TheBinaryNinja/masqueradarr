masqueradarr · documentation zero → hero

Self-hosted IPTV, aggregated.

Aggregating scattered IPTV sources behind a single, trusted identity.

masqueradarr is a self-hosted IPTV aggregator. It pulls channel playlists (M3U) and guide data (EPG/XMLTV) from a range of online IPTV services, normalizes them into one catalog, and serves them back as a single, unified, standards-compliant playlist + guide — behind one trusted identity that your media apps and IPTV clients can talk to.

◊ What it does

Four jobs, one container

masqueradarr is the ground-up successor to TVApp2. Where the original kept static .m3u files fresh, masqueradarr runs a live, resolve-on-demand engine — and wraps it in a real management app.

● aggregate & normalize

Many providers → one catalog

Pulls M3U playlists and EPG/XMLTV guides from ~17 provider adapters plus your own URL / file / HDHomeRun imports — and, optionally, a Rebel IPTV companion — and normalizes them into a single, deduplicated channel catalog.

● resolve on demand

No dead URLs on disk

Every stream is resolved at play time, which is what makes authenticated, token-gated and rotating-mirror sources possible — captured logins, per-play signed URLs renewed before they expire, and failover to ordered backup channels.

● deliver anywhere

One endpoint for every client

An in-app player, a pop-out Ultimate Video Player launched straight from any playlist row, and per-user, tokenized .m3u + XMLTV export for TiviMate, VLC, Plex, Jellyfin and Emby — bytes served by a durable Rust proxy engine.

● own the whole stack

Users, telemetry, schedule

scrypt users with roles and per-user access lists, live viewer/bandwidth telemetry, MongoDB-backed logs, a cron scheduler, and full-system backup / restore.

◊ Recently added

What's new since the last docs pass

The headline changes on main, each documented on the page it belongs to.

● rebel iptv companion

A second server, folded in

Run Rebel IPTV beside masqueradarr with one switch: its channels and guide join your catalog, it's updated (with rollback) from Settings, and its dashboard pops up behind your admin login. Rebel IPTV →

● playlist domain / configuration

Providers that move, in one JSON

Settings → Advanced holds one validated JSON document with each moving provider's enable, domain and options (DaddyLive's mirror and default player, dulo's domain). Test probes the unsaved text. Getting started →

● ultimate video player

Play a whole playlist

A play button on every playlist row — on Playlists and the Dashboard — opens the pop-out Ultimate Video Player scoped to that playlist, with an A–Z / channel-number switcher. Operations →

● data-plane dns

One set of nameservers

The Settings DNS nameservers now govern the Rust data plane's upstream lookups as well as Node's, with an OS-resolver fallback, and apply live. Video proxy engine →

● no-avx hosts

An AIO image for older CPUs

Synology NAS, Atom / Celeron and kvm64 VMs lack AVX, which MongoDB 7 needs. The mongo4.4- tags of the all-in-one image run MongoDB 4.4 instead (fresh /data volume; move data via backup / restore). Getting started →

● stream durability

Expiring URLs, disguised segments

Signed targets are renewed ahead of expiry without dropping the ring, disguised segments are unwrapped, and raw-TS joins open on a keyframe. Local origin →

◊ The shape of it

One picture: clients, the container, the upstreams

Two processes ship in the same container. Your browser and IPTV clients talk to the Express control plane (Node), which owns MongoDB and drives a Rust data-plane sidecar (masq-proxy) that actually moves the stream bytes.
